# Калибровочная панель цветов

Локальная веб-панель для проверки обложек, спектра и баланса белого на
колонках с LED-кольцом. Панель не входит в пакет плагина: браузер считает
цвет, а локальный мост по кнопке передаёт **один кадр** на выбранную колонку.
Фото никуда не загружается.

Поддерживаются кольца на 3, 6 и 89 светодиодов, включая framebuffer-кольцо
Station 2.

## Что нужно

- Python 3.8+ и `adb` на машине, которая видит колонки по сети.
- Установленный Station-airplay 2.1.5+ и запущенный плагин.
- ADB-доступ к колонке (`adb connect <ip>:5555`). Панель ходит в колонку
  только через ADB: читает токен Luna и, для Station 2, кладёт файл кадра.

## Развёртывание

1. Получите репозиторий и перейдите в каталог панели:

   ```sh
   git clone https://github.com/ryysel/Station-airplay.git
   cd Station-airplay/tools/color-panel
   ```

   Изменения панели уже в `main` и входят в 2.1.6.

2. Создайте свой конфиг из примера:

   ```sh
   cp targets.example.json targets.json
   ```

   Впишите реальные адреса колонок. `targets.json` в `.gitignore` — свои
   адреса в репозиторий не коммитьте.

3. Подключите колонки по ADB и проверьте, что они видны:

   ```sh
   adb connect 192.168.1.50:5555
   adb devices
   ```

4. Запустите мост:

   ```sh
   python3 panel-server.py
   ```

   По умолчанию он слушает `0.0.0.0:8799`. Порт и адрес можно задать
   переменными `PANEL_HOST` и `PANEL_PORT`.

5. Откройте `http://<адрес-машины>:8799/` в браузере. Список колонок
   подтянется из `targets.json`.

Мост выполняет `adb shell` и пишет на колонки, поэтому запускайте его только
в доверенной сети и не выставляйте порт в интернет.

## targets.json

| Поле | Обязательно | Смысл |
|---|---|---|
| `label` | нет | Подпись в списке колонок. |
| `serial` | да | Адрес для ADB, обычно `<ip>:5555`. |
| `api` | для `transport: api` | Runtime API плагина Luna. |
| `transport` | нет | `api` (по умолчанию) или `file` для Station 2. |
| `path` | для `transport: file` | Файл кадра, который читает плагин. |
| `leds` | да | 3, 6 или 89. |
| `matrix` | нет | Имя стокового профиля (`red`, ...) или `null`. |
| `swap` | нет | Менять R/B местами для старой Luna (Mini 2). |
| `neutral_black` | нет | Чёрная обложка гасит кольцо (Lite 2) или даёт свой fallback. |
| `neutral_gain` | нет | Не применять ползунки баланса белого (Station 2). |
| `black_floor` | нет | Минимальная яркость чёрной обложки, 0…1 (Station 2: 0.07). |
| `saturation` | нет | Растяжение насыщенности приглушённых обложек (Station 2: 1.35). |

Для Mini 2: `matrix: "red"`, `swap: true`, `neutral_black: false`.
Для Lite 2: `matrix: null`, `swap: false`, `neutral_black: true`.
Для Station 2: `transport: "file"`, `leds: 89`, `neutral_gain: true`,
`black_floor: 0.07`, `saturation: 1.35`.

## Как пользоваться

1. Выберите колонку в списке сверху.
2. Лучше поставить AirPlay на паузу. Для Station 2 пауза не обязательна:
   пока файл кадра существует, плагин держит кольцо и не перерисовывает его
   спектром.
3. Выберите готовую обложку или загрузите своё фото. Точки на фото
   показывают выборку 64×64, светлая зона — пиксели, из которых взят
   доминирующий цвет.
4. Нажмите **«показать на колонке»**. Превью замирает, на колонку уходит
   один кадр.
5. **«погасить»** возвращает кольцо штатной индикации.
6. Для белого и серого двигайте **«Баланс белого · R/G/B»**. Ползунки влияют
   только на отправляемый кадр; превью показывает исходный цвет обложки.
   Подобранные значения переносятся в `spectrum_gain_r/g/b` конфигурации
   плагина. Для Station 2 ползунки не применяются: панель уже нейтральная.
7. Проверьте красный, зелёный, синий, жёлтый, белый, серый и чёрный.
   Если красный выглядит синим, а синий красным — это порядок каналов, а не
   баланс белого. Если жёлтый выглядит бело-зелёным — не хватает насыщенности
   (`saturation`).

## Station 2

У Station 2 нет sysfs-кольца: это 89-пиксельный `/dev/fb0` (84 RGBW-диода
панели плюс логотип), которым владеет `led-animator` в `maind --platformd`.
Панель не ходит в Luna LED API, а кладёт JSON через ADB в
`/run/station-airplay/test-frame.json`:

1. плагин видит файл, забирает framebuffer у `led-animator` через `ptrace`
   и рисует кадр;
2. пока файл существует, кольцо принадлежит панели — спектр его не трогает;
3. «погасить» удаляет файл, плагин возвращает кольцо прошивке;
4. если вкладку закрыли, кадр снимается сам через 5 минут.

Пиксель панели — **RGBW**: четвёртый байт управляет белым диодом, поэтому
цветные кадры пишутся как `R, G, B, 0`. Общая яркость — отдельная настройка
панели `/sys/class/backlight/fb0/brightness` (0…255); панель её не меняет.
Если кольцо кажется потухшим, проверьте яркость в приложении «Дом с Алисой».

## Ограничения

- Превью считает алгоритм, но не имитирует оптику, диффузор и реальную
  яркость. Значения одной модели нельзя вслепую переносить на другую.
- На Mini 2 и Lite 2 во время воспроизведения плагин перерисовывает кольцо
  10 раз в секунду и затрёт тестовый кадр — проверяйте на паузе.
- Панель проверяет цвет, а не заменяет прослушивание.

## Если не работает

- `station-airplay не запущен` — плагин не работает или не тот `serial`.
- `в окружении плагина нет LUNA_API_TOKEN` — плагин запущен не через Luna;
  проверьте установку пакета.
- Страница без списка колонок — не запущен `panel-server.py`; открывайте
  через `http://<host>:8799/`, а не как файл.
- «показать» отвечает ошибкой для Station 2 — нужен плагин 2.1.5+ с хуком
  `/run/station-airplay/test-frame.json`.
- Кольцо не вернулось — нажмите «погасить» ещё раз или перезапустите плагин.

Методика проверки по моделям — в [docs/COLOR_CHECK.md](../../docs/COLOR_CHECK.md).
