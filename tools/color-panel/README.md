# Калибровочная панель цветов

Локальная веб-панель для проверки обложек и баланса белого на колонках с
LED-кольцом. Она не входит в пакет плагина и не отправляет фото: браузер
считает цвет, а мост по кнопке передаёт один кадр в runtime LED API Luna.

## Что нужно

- Python 3.8+ и `adb` на машине, которая видит колонки по сети.
- Колонка с включённым плагином Station-airplay и доступным runtime API
  (`/api/runtime/airplay.airplay-luna`).
- Разрешение ADB на колонке (обычно `adb connect <ip>:5555`).

## Настройка

1. Скопируйте пример и заполните свои адреса:

   ```sh
   cp targets.example.json targets.json
   ```

   В `targets.json` для каждой колонки нужны `label`, `serial`, `api`, `leds`
   и признаки `matrix`/`swap`/`neutral_black`:

   - `matrix`: имя стокового профиля (`red`, `blue`, ...) или `null`.
     Mini 2 использует `red` и `swap: true`; Lite 2 — `null`/`false`.
   - `neutral_black`: `true`, если чёрная обложка должна полностью гасить
     кольцо (Lite 2). Mini 2 сохраняет свой исторический сине-серый fallback.
   - `leds`: 3 для Lite 2, 6 для Mini 2.

2. Запустите мост:

   ```sh
   python3 panel-server.py
   ```

3. Откройте `http://<адрес-машины>:8799/` в браузере.

Токен Luna читается мостом из окружения запущенного плагина через ADB и
никогда не попадает в браузер. Запускайте панель только в доверенной сети.

## Как проверять

1. Выберите колонку в списке сверху.
2. Поставьте AirPlay на паузу. Пока играет музыка, плагин перерисовывает
   кольцо 10 раз в секунду и затрёт тестовый кадр.
3. Выберите готовую обложку или загрузите фото. Точки на фото показывают
   выборку 64×64, светлая зона — пиксели, из которых взят доминирующий цвет.
4. Нажмите **«показать на колонке»**. Панель замирает и отправляет один кадр.
5. **«погасить»** выключает тестовый кадр.
6. Для белого/серого двигайте **«Баланс белого · R/G/B»**. Ползунки влияют
   только на отправляемый кадр; превью показывает исходный цвет обложки.
   Подобранные значения переносятся в `spectrum_gain_r/g/b` конфигурации
   плагина.
7. Проверьте красный, зелёный, синий, жёлтый, белый, серый и чёрный. Если
   красный выглядит синим, а синий красным — это порядок каналов, а не
   баланс белого.

## Ограничения

- Превью считает алгоритм, но не имитирует оптику, диффузор, реальную
  яркость и стоковую матрицу Luna.
- Значения одной модели нельзя вслепую переносить на другую: у Mini 2 и
  Lite 2 разные LED-профили.
- Панель показывает расчётный цвет и отправляет его через тот же API, что и
  плагин; это инструмент проверки, а не замена прослушиванию.

Методика проверки по моделям — в [docs/COLOR_CHECK.md](../../docs/COLOR_CHECK.md).
